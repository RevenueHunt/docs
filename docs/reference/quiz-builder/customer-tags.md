# Customer Tags

=== "Shopify"


    You can create custom tags and link them to choices in the quiz. Customer tags are useful for segmenting customers and email marketing. See [how to add and use customer tags](/how-to-guides/use-customer-tags/) for the full walkthrough.

    To add customer tags to choices, go to [Questions](/reference/quiz-builder/questions/), select a multiple-choice question, then a choice and open the [`Choice settings`](/reference/quiz-builder/questions/#choice-settings).

    ![Opening the Choice settings for a choice](/images/manual_shopifyV2_quizbuilder_quizbuilder_questions_blocksettings_multiplechoice_choicesettings.png)

    Under [Choice settings](/reference/quiz-builder/questions/#choice-settings), find the `Customer tags` section and click on it to open the settings.

    ![The Customer tags section of the Choice settings](/images/manual_shopifyV2_quizbuilder_quizbuilder_questions_choicesettings_customertags.png)

    Click `Search or create tags` to pick a tag to link to this choice or start typing the name to create a new tag.

    ![Creating a new tag from the search field](/images/manual_shopifyV2_quizbuilder_quizbuilder_questions_choicesettings_customertags_createnew.png)

    Confirm by clicking on `Create new tag`.

    All the tags you create will be visible at the bottom in grey.

    ![The tags linked to a choice, listed below the field](/images/manual_shopifyV2_quizbuilder_quizbuilder_questions_choicesettings_customertags_tags.png)

    When a customer selects this choice, every linked tag is added to their customer profile. Use the tags to segment your customers in your CRM.

    Back in the question, every choice shows its own `Customer tags` column, with the number of linked tags above them. Click the `x` on a tag to unlink it from that choice.

    ![Two customer tags linked to each choice, in the question and in the Choice settings](/images/manual_shopifyV2_quizbuilder_quizbuilder_questions_choicesettings_customertags_linked.png)


=== "Shopify (Legacy)"

    ![The Customer Tags section in the legacy app](/images/manual_quizbuilder_customertags.png)

    In the Customer Tags section, you can create custom tags and link them to choices in the quiz. Customer tags are useful for segmenting customers and email marketing. See [how to add and use customer tags](/how-to-guides/use-customer-tags/) for the full walkthrough.

    ![Adding a tag next to a choice](/images/manual_quizbuilder_customertags_addtag.png)

    To add a new tag, type its name in the white bar next to one of the choices. Confirm it by clicking `Add this as a new customer tag`.

    The new tag then shows as an available option whenever you select another choice.

    ![A tag linked to a choice](/images/manual_quizbuilder_customertags_tagadded.png)

    You can create as many tags as you like. You can link as many tags as you like to the same choice.
