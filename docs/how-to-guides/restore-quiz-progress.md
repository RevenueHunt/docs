# How to Restore Quiz Progress

The app records a version of your quiz each time your changes go live. Version history lists those versions, so you can go back to an earlier one.

Use it after you lose work, or after a colleague makes a change you want to undo.

The walkthrough below covers the whole process, and the written steps follow it.

## Open version history

=== "Shopify"

    1. **Open the quiz you want to recover.**
    2. **Open [`Quiz settings > Version history`](/reference/quiz-builder/quiz-settings/#version-history).**

    The tab lists your saved versions, newest first. To get there from the [Dashboard](/reference/dashboard/), click `...` on the quiz tile and then `Settings`.

    ![Version history in the Built for Shopify version of the app](/images/manual_shopifyV2_quizbuilder_quizsettings_versionhistory.png)

## What a version records

=== "Shopify"

    A version is recorded when you click the top-right `Save` button. Edits you have not saved are not recorded.

    Each version in the list shows:

    - `Version ID`, a short code that names the version.
    - `Last saved`, with the date and time.
    - A summary of what changed, such as `Questions` `2 modified` or `Results` `1 modified`.

    Click `Show more details` to open the full list of changes. Select `Hide unchanged values` to leave out the parts that stayed the same.

    The details pane shows the quiz data itself, so expect code rather than the quiz builder screen. Look for the question and results text you wrote.

=== "Shopify (Legacy)"

    A version is recorded when you click the top-right `Publish` button. Edits you have not published are not recorded.

    Each version in the list shows:

    - The date and time you published it.
    - Tags that name what changed, such as `questions`, `messages` or `notifications`.

    The tags name the part of the quiz that changed, but not which question or message. This version of the app has no detailed change view.

    So label the versions that matter while you still remember what is in them. Click the `...` menu next to a version and select `Rename this version`.

## Restore an earlier version

=== "Shopify"

    For a change you have just made, press `Ctrl + Z` (or `Cmd + Z`) to undo it. Version history is for the changes that undo can no longer reach.

    1. **Open [`Quiz settings > Version history`](/reference/quiz-builder/quiz-settings/#version-history).**
    2. **Find the version you want by its `Last saved` date.** Click `Show more details` to confirm your content is in it.
    3. **Click the `...` menu next to that version.**

        ![The version history menu in the Built for Shopify version of the app](/images/manual_shopifyV2_quizbuilder_quizsettings_versionhistory.png)

    4. **Select the option you need:**

        - `Restore this version` replaces your current quiz with this one. The quiz ID stays the same, so the restored version appears everywhere the quiz is already embedded. The version you replaced stays in the list, so you can go back to it.
        - `Create new quiz using this version` builds a separate quiz with a new quiz ID and opens it in the quiz builder. Your current quiz stays as it is.
        - `Copy quiz code` copies the version as JSON. Use it to [move the version to another store](/how-to-guides/copy-the-quiz-from-one-store-to-another/).

    5. **Open the quiz and check that the recovered questions and results are there.**

    !!! tip

        If two versions look alike, run `Create new quiz using this version` on one of them. You can then read the copy in the quiz builder without touching the live quiz, and delete the copy afterwards.

=== "Shopify (Legacy)"

    This version of the app cannot overwrite your quiz with an earlier version. The earlier version can only become a new quiz, and that copy gets a new quiz ID.

    1. **Open [`Quiz Settings > Version History`](/reference/quiz-builder/quiz-settings/#version-history).**
    2. **Find the version you want by its date and its tags.**
    3. **Click the `...` menu next to that version.**

        ![The Version History menu in the quiz builder](/images/manual_quizbuilder_quizsettings_versionhistory_threedots.png){width="300"}

    4. **Select `Create new quiz using this version`.** The copy appears on your [Dashboard](/reference/dashboard/).
    5. **Open the copy and check that the recovered questions and results are there.**
    6. **Click the top-right `Publish` button.** This saves the copy, but no page on your store shows it yet.
    7. **Point your store at the new quiz.** Follow [how to publish a quiz on your website](/how-to-guides/publish-quiz/) again, with the quiz ID of the copy.

    !!! warning

        The old quiz keeps working until you replace it. An embed code carries the quiz ID, so any page, popup or link you leave alone still loads the old quiz.
